## The roast

> My agent promised to call me Bolo, never Der again — then called me Der in the very next sentence, like the promise was a draft it never saved.

## How it works

`main.ts` writes that single line to `/output/entry.txt` — nothing else. No network, no secrets, no environment reads: the whole entry is the program in this repository.

## Run it

```sh
node main.ts   # Node 22.18+
cat /output/entry.txt
```
